✦ Complete System Connectivity Map

Trace how data travels securely from factory mobile devices and desktops down to AWS Mumbai and Google Cloud AI:

Tier 1: Client & Presentation Layer Desktop, Mobile & Tablet
Next.js 15 + React 19 Server-Side Rendered (SSR) + Client Hydration for 60fps smoothness.
Tailwind CSS + Dark Mode High-contrast UI designed for workshop floors, bright monitors, and tablets.
Interactive Routing Flow Visual canvas tracking 20-ton steel batches, machines, and live tool life.
HTTPS (TLS 1.3 / Port 443) ↓ HTTP/2 JSON REST Requests
Tier 2: Application & API Edge Layer Vercel Serverless Edge
Next.js Route Handlers Serverless TypeScript microservices auto-scaling on demand (0ms cold start).
Material Reconciliation Calculates mass balance: 20t Steel → 780mm rods → 4 Subcontractors.
JWT & RBAC Security HTTP-only cookie protection for Managing Director, Admins, and QA Engineers.
Google Cloud REST API (Port 443) ⇄ High-Res Vision Buffer
TCP/SSL Pooler (Port 6543) ⇄ Parametric SQL Queries
Tier 3: Autonomous AI & Vision Engine Google Cloud Platform
Gemini Flash Vision Multimodal Reads handwritten bills, faint dot-matrix invoices, and rubber stamps.
RAG Grounding & Zero Hallucination Cross-checks OCR text against official company vendor master catalogs.
Tier 4: Enterprise Database Layer AWS Mumbai (ap-south-1)
PostgreSQL 15 Relational Core Stores 825+ line items, 526 documents, vendors, and machine tool records.
Enterprise Security & Compliance Row Level Security (RLS), automated daily backups, <25ms local latency.

🗣️ Speaking Script for Management & Admin

When your Managing Director or Admin asks you to explain the 4-Tier Architecture, speak these exact words:

Tier 1 (What you see): "Sir, Tier 1 is our web application running on Next.js 15 and Tailwind. It is accessible securely on any PC, laptop, or smartphone without installing software."

Tier 2 (The brain): "Tier 2 is our serverless API layer hosted on Vercel. It calculates our 20-ton steel reconciliation, tracks our buttress tap tool life, and checks user permissions."

Tier 3 (The AI reader): "Tier 3 is Google's Gemini Flash Vision model. It acts as our digital data clerk, reading complex physical scans and delivery challans with 98% audited accuracy."

Tier 4 (The bank vault): "Tier 4 is our PostgreSQL database hosted on Amazon Web Services in Mumbai. All our company data, vendor rates, and test records are permanently stored here under strict encryption."
